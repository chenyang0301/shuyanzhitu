客户常问的 8 个问题

关于国产 GPU 适配、信创改造与数字孪生，先把你最关心的说清楚。

需要驻场交付吗？▼
默认远程为主、高效协同；必要时可按项目阶段驻场支持。我们更看重"把事交付清楚"，而非人在不在现场。
涉及的数据安全如何保障？▼
敏感数据可在客户本地环境开发，不离开内网；可签署保密协议（NDA），按客户安全规范执行。
国产 GPU 实在适配不了怎么办？▼
提供降级 / fallback 方案（如改用兼容渲染管线、降低精度、2.5D 表达），确保"至少能跑、能看、能用"，再逐步优化。
一个项目大概多久？▼
演示 Demo 通常 1–2 周；标准数字孪生项目 1–3 个月（视范围与数据接入复杂度），小步交付、边做边验。
你们能适配哪些国产显卡？▼
自有 Glenfly 格兰菲测试机，问题可真实复现修复；景嘉微、摩尔线程等已纳入适配路线，按项目推进。
小公司 / 单人，能接得住我的项目吗？▼
可以。我们用"分包控产能"的打法：建模、UI、驻场外包，我方抓架构与核心 GPU 适配，单人也能交付大项目。
报价透明吗，会不会中途加价？▼
接单先出一页纸 SOW：做什么、不做什么、交付物、时间、价格区间。范围锁定后不随意加价，变更单独确认。
怎么开始？▼
先免费沟通诊断 → 出范围与报价 → 小单试合作 → 满意后再扩大。低风险起步，先看效果。

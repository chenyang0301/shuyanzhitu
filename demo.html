运行说明

Demo 运行环境 & 支持清单

看懂这段，能少走 90% 的弯路：Demo 跑不起来，多半不是 Demo 的问题，是环境没对齐。

① 运行环境要求

  • 图形接口：浏览器需支持 WebGL / WebGL2（现代浏览器默认开启）。
  • 网络：首次加载需联网拉取 Cesium / Leaflet 引擎与公开地图瓦片（约数 MB）。
  • 操作系统：Windows / 统信 UOS / 麒麟 / 中标麒麟 / 方德 / macOS 均可。
  • 硬件加速：浏览器「硬件加速」需开启，否则三维会卡成幻灯片。

② 支持的国产浏览器

360 安全浏览器（信创版/极速模式） 红莲花安全浏览器 奇安信可信浏览器（政企版） 统信 UOS 浏览器 银河麒麟浏览器 中标麒麟安全浏览器 飞腾/兆芯平台 Chromium 系 Chrome / Edge / Firefox（开发演示）

③ 重点适配的国产显卡

景嘉微 JM7200 / JM9100 / JM9230 摩尔线程 MTT S10 / S30 / S80 / S3000 格兰菲 Glenfly（Arise 系列） 芯动科技 风华系列 壁仞 BR100 系列（计算卡） 寒武纪 / 昇腾 Atlas（AI 推理）

⚠ 老驱动 + 国产显卡组合下出现花屏 / 卡顿 / 黑屏 / 裂块，正是我们「GPU 故障修复」要解决的典型场景。

看不了在线 Demo 也不用急：部分客户网络差、或浏览器不支持 WebGL，打不开上面的实时演示。 下方我们准备了静态样例截图 + 效果录屏，所有人都能直观看到效果；需要可交互版本，点「预约诊断」我们单独发你。
